# Description

This repository features some Julia [Pluto notebooks](https://plutojl.org/), in order to use the notebooks properly, it is better to run Pluto in the root of this project.

```sh
cd PlutoProjects/

# Open the julia repl
julia

# Import Pluto
using Pluto

# Run Pluto
Pluto.run()
```
The browser should open on port `localhost:1234`, and you will be able to pick a notebook and run it.
